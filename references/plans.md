# 과금 방식, 남은 사용량, 예산 상태별 조정

2026-10-29 기준. [공식]은 벤더 문서, [3자]는 서드파티 보고, [추론]은 이 스킬의 설계 판단이다. 한도 수치는 자주 바뀌므로 배치 시점에 다시 확인한다.

## 1. 과금 방식별 비용 단위

| 과금 방식 | 예 | 비교 단위 | 모델 간 상대 비용 |
| --- | --- | --- | --- |
| 구독 (창 한도) | Claude Pro·Max, ChatGPT Plus·Pro·Business(Codex), Antigravity Pro·Ultra, Factory | 5시간·주간 한도 소진량 | 2절 |
| 크레딧 (토큰 × 모델 단가) | GitHub Copilot AI Credits, Cursor 선불 크레딧(서드파티 모델), OpenCode Go·Zen, Kilo, Amp | 차감 크레딧 | API 단가 비율과 같다 [공식] |
| API 종량제 | Anthropic·OpenAI API 키 | 작업당 달러 | `references/models.md`의 작업당 비용 표 |

여러 과금을 함께 쓰면(예: Claude Max와 ChatGPT Plus) 각각의 예산 상태를 따로 정한다.

## 2. 구독에서 모델별 소진 속도

**Codex (ChatGPT Plus·Business, 5시간당 로컬 메시지 추정치)** [공식]

| 모델 | 5시간당 메시지 | 크레딧 단가 (Terra = 1) |
| --- | --- | --- |
| GPT-6 Luna | 350~3,000 | 0.1 |
| GPT-6.1 Terra | 35~285 | 1 |
| GPT-6.1 Sol | 15~160 | 2 |
| GPT-6 Astra | 5~45 | 10 |

- OpenAI: "같은 사용 한도로 Terra는 Sol·Astra보다 상당히 많은 작업을 처리한다" [공식].
- Pro는 5시간 한도가 없고 주간 한도만 적용될 수 있다 [공식].
- Fast 모드는 한도를 2.5배, Ultrafast는 8배 빨리 쓴다 [공식].
- 클라우드 작업은 로컬 메시지보다 많이 쓸 수 있다 [공식].

**Claude (Pro·Max·Team·Enterprise)**

- 5시간 세션 한도와 주간 한도를 모든 모델이 함께 쓰고, Claude 앱과 Claude Code가 공유한다 [공식].
- 모델별 소진 비율은 공개되지 않았다. API 단가 비율(Opus 5.5 = Sonnet 5.5의 2배, Sonnet 5.5 = Haiku 5.5의 20배)을 약한 추정치로만 쓴다 [추론].
- Anthropic 권고: 대부분의 코딩은 Sonnet, 복잡한 설계와 다단계 추론에만 Opus, 단순 하위 에이전트는 Haiku [공식]. 이 스킬의 배치표는 독립 측정을 따르므로 다를 수 있다. 예산이 여유일 때는 배치표를, 부족할 때는 이 권고 쪽으로 기운다.
- Max에서 Fable을 쓰면 일반 주간 한도도 빨리 줄어든다 [공식]. Fable은 배치 대상이 아니지만 남은 사용량에 영향을 준다.
- "Opus limit"처럼 모델 계열 한도 메시지가 나오면 다른 계열로 바꿔 계속할 수 있다. 세션·주간 한도 메시지에서는 모델을 바꿔도 풀리지 않는다 [공식].

**Antigravity**: 한도 수치와 모델별 소진 비율이 공개되지 않았다 [공식]. Claude 5.5는 유료 Pro·Ultra에서만 쓸 수 있다는 보고가 있다 [3자].

**OpenCode Go**: 모델마다 월 달러 한도가 있고, 5시간 한도는 월 한도의 20%, 주간 한도는 50%다 [공식].

## 3. 남은 사용량 확인

| 하네스·과금 | 확인 방법 | 에이전트가 직접 읽을 수 있는가 |
| --- | --- | --- |
| Claude Code (Pro·Max) | `/usage`, `/status`, 상태 표시줄 JSON의 `rate_limits.five_hour`·`rate_limits.seven_day`(`used_percentage`, `resets_at`) [공식] | 상태 표시줄 스크립트가 값을 파일로 남기면 읽을 수 있다 [추론]. 아니면 사용자에게 묻는다 |
| Codex | `/status`의 5시간·주간 남은 %와 리셋 시각, 사용량 대시보드 [공식] | 아니다. 사용자에게 묻는다 |
| GitHub Copilot | `/usage`, 푸터, 월간 크레딧 대시보드(매월 1일 00:00 UTC 리셋) [공식] | 아니다 |
| Cursor | 에디터 설정의 사용량 [공식] | 아니다 |
| Factory Droid | `/limits` (5시간·7일·30일) [공식] | 아니다 |
| Amp | `amp usage` (잔액) [공식] | 셸 명령으로 읽을 수 있다 |
| Antigravity | 설정 화면 [공식] | 아니다 |
| OpenCode Go | 콘솔 [공식] | 아니다 |
| API 키 | 응답 헤더 `anthropic-ratelimit-*-remaining`, `x-ratelimit-remaining-*`, 월 지출 상한 [공식] | 직접 호출할 때만 |

읽을 수 없으면 사용자에게 한 번 묻고, 프로필 블록에 확인 방법을 적어 두게 제안한다.

## 4. 예산 상태

벤더가 정한 기준은 없다. 아래는 이 스킬의 기준이다 [추론].

- 5시간·주간(크레딧은 월간) 창 중 더 나쁜 쪽을 기준으로 한다. 주간·월간 창은 회복이 느리므로 같은 사용률이면 더 나쁘게 본다.
- 소진 속도 = 사용률 ÷ 창에서 지난 시간의 비율. 리셋 시각과 창 길이로 계산한다.

| 상태 | 조건 |
| --- | --- |
| 여유 | 사용률 50% 미만이고 소진 속도 1.0 이하 |
| 보통 | 사용률 50~80%, 또는 소진 속도 1.0 초과 |
| 부족 | 사용률 80% 이상, 또는 지금 속도로 리셋 전에 100%에 닿을 것으로 보임 |
| 알 수 없음 | 값을 읽을 수 없고 사용자도 모름 |

API 종량제는 사용자가 정한 예산 대비 지출로 같은 기준을 쓴다. 예산이 없으면 "여유"로 본다.

## 5. 예산 상태별 조정

**여유**: 배치표의 1순위를 쓴다.

**보통**: 아래를 순서대로 적용한다.

1. Fast·Ultrafast 같은 속도 옵션을 끈다.
2. 같은 검토를 반복하지 않고, 하위 에이전트 수를 줄인다. 에이전트 팀은 토큰을 크게 늘린다 [공식].
3. T0·T1 단계를 계열에서 가장 싸게 돌린다. OpenAI 계열은 T0 Luna low, 기계적 T1 Luna medium, 그 밖의 T1 Terra low. Claude 계열은 T0·T1이 이미 대부분 Haiku이므로, T1 정밀 시각 판독(Opus high)만 Sonnet high로 내린다. T1 판단(Sonnet)은 Haiku로 내리지 않는다.
4. T2 이상은 유지한다.

**부족**: 보통의 조정에 더해 아래를 적용한다.

1. T2 이상은 모델을 바꾸기 전에 effort를 한 단계 낮춘다(예: Sol high → medium, Opus high → medium).
2. OpenAI 계열에서 Astra를 쓰지 않는다(Terra의 10배 단가). T3도 Sol high로 대신하고 그 사실을 알린다.
3. 다른 과금에 여유가 있으면 T0·T1 단계를 그쪽으로 넘기자고 제안한다. 계열을 넘는 인계 비용을 함께 적는다. 하네스에서 오픈 모델을 쓸 수 있으면 `references/placement.md`의 오픈 모델 대안도 후보로 올린다.
4. 급하지 않은 T1 판단 단계(남은 작업 정리, 추가 리뷰)는 미루자고 제안한다.

**소진**: 작업을 멈추고 보고한다. 선택지를 함께 제시한다: 리셋 시각까지 기다리기, 다른 과금으로 넘기기, 추가 사용(유료 크레딧) 켜기. 추가 비용이 드는 선택은 사용자 승인 없이 하지 않는다.

**알 수 없음**: 배치표의 1순위를 쓰되 한도 경고나 "limit" 오류가 나오면 즉시 다시 정한다.

**낮추지 않는 단계**: 권한 경계가 있는 조작, 사람에게 나가는 최종본, 보안 리뷰는 예산 상태와 관계없이 등급과 모델을 낮추지 않는다. 예산이 모자라면 멈추고 묻는다.

## 6. 과금별 주의

- Cursor 현행 플랜에서 Claude·GPT 같은 서드파티 모델은 주간 풀이 아니라 선불 크레딧에서 API 정가로 빠진다 [공식]. 크레딧 과금으로 다룬다.
- Copilot은 크레딧을 다 쓰면 싼 모델로 자동 전환되지 않는다 [공식].
- Claude Code에서 한도에 닿은 뒤 리셋까지 기다렸다가 자동 재개하는 설정이 있다(`/rate-limit-options`) [공식].
- GLM·Kimi·MiniMax 코딩 플랜의 한도 수치는 출처마다 달라 신뢰도가 낮다 [3자]. 사용자에게 확인한다.
