# Privacy Policy

Last updated: 2026-10-28

`model-routing` is a Claude Code plugin and agent skill that contains Markdown instructions only (`SKILL.md`, `README.md`). It has no executable code, MCP servers, hooks, network calls, or backend service.

## Data the plugin handles

- **Collection:** The plugin does not collect personal data or any other data.
- **Storage:** The plugin does not store data. It has no server or database.
- **Transmission:** The plugin does not send data to the author or to any third-party service.
- **Retention:** No data is received from Claude, so none is retained.

When you use the skill, its instructions are read by your coding agent (for example Claude Code or Codex) like any other text in your session. How that agent and its model provider handle your session data is governed by their own privacy policies.

## Installation tools

Installing the plugin through a third-party tool, such as `npx skills`, or through GitHub is subject to that tool's or service's own privacy policy. The plugin itself adds no data collection to those tools.

## Children

The plugin is a developer tool and is not directed at children under 18.

## Changes and contact

Changes to this policy are recorded in this repository's commit history. For questions, open an issue at https://github.com/sangwookp9591/model-routing/issues.
